Detailed Description

The NWBFile class provides an interface for setting up and managing the NWB file.

Note
Handling of Optional Paths: Some groups in the NWB file structure (e.g., /events, /intervals) are optional and are not created by default during initialize(). These groups are created automatically on-demand when objects are added to them (e.g., via createEventsTable or createTimeIntervals). If you are creating objects in these paths manually, you can use helper methods like requireEventsGroup or requireIntervalsGroup to ensure the parent groups exist.

Status NWBFile::setSessionStartTime ( const std::string & sessionStartTime)

Change the session start time of an initialized file.

Overwrites the value of /session_start_time, so this is also possible while recording (e.g., in SWMR mode), for applications that know the start time only after the file was created. The new value must not be longer than the value written by initialize() (e.g., a time from formatTime() if the default value of initialize() was used).
