# AqNWB Agent Instructions

AqNWB is a C++17 library for acquiring neurophysiology data directly in the NWB format.

- **Repository guide:** `.github/copilot-instructions.md` covers the layout, build, test, lint, and CI workflows. It applies to all coding agents, not only Copilot.
- **Developer documentation:** `docs/pages/devdocs/` is the source of truth for design decisions. Key pages:
  - `registered_types.dox`: RegisteredType, the field macros, the Spec convention, and `generate-types`
  - `integrating_extensions.dox`
  - `testing.dox`

## Skills

Skills are task-specific instructions in the open Agent Skills format (`SKILL.md` with `name`/`description` frontmatter):

| Skill | Use it to |
|---|---|
| `.agents/skills/add-neurodata-type/SKILL.md` | add a neurodata_type to AqNWB, finish code generated by `aqnwb_utils.py generate-types`, or resolve `AQNWB-TODO` comments |

## Ground rules

- **Before committing:** build and run the tests (`cmake --preset=ci-<os>`, `cmake --build build`, `ctest --test-dir build --output-on-failure`), format with clang-format, and add a `CHANGELOG.md` entry.
- **Pull requests:** create them as drafts. A maintainer has to review them before they are merged.
