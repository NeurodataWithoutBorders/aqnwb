Detailed Description

Configuration of the HDF5 raw data chunk cache used for each dataset of a file (see H5Pset_cache), passed to HDF5IO::open, HDF5IO::openS3, and HDF5IO::openRemote.

HDF5 caches chunks of each open dataset in a per-dataset cache (by default, e.g., 1 MiB in HDF5 1.14 and 8 MiB in HDF5 2.2, see HDF5IO::getDefaultChunkCacheNumBytes()). If a chunk is larger than the cache, every partial write to the chunk (e.g., writing one channel at a time to a dataset that is chunked over many channels) results in a read-modify-write of the whole chunk on disk, which is very slow. Set the cache to (a multiple of) the size of the chunks being written, e.g., based on the number of channels.
