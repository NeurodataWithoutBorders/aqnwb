Detailed Description

Optional metadata of the experiment in /general.

All fields are optional; only the fields that are set are written. Pass an instance of this struct to NWBFile::initialize(). Field names follow PyNWB's NWBFile arguments (e.g., stimulusNotes for /general/stimulus). data_collection is set with the dataCollection argument of NWBFile::initialize().
