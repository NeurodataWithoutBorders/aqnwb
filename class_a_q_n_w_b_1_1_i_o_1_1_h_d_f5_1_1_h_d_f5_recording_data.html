Detailed Description

Represents an HDF5 Dataset that can be extended indefinitely in blocks.

This class provides functionality for reading and writing blocks of data to an HDF5 dataset.

◆ getMemType()

const DataType & HDF5RecordingData::getMemType ( const IO::BaseDataType & type)
private

Returns the HDF5 type in memory for writes with the C++ API.

Strings and array types have no predefined HDF5 type, so HDF5IO::getNativeType creates a new type for every call (e.g., H5Tcopy, H5Tset_size and H5Tset_cset for a string, H5Tarray_create for an array type). This is a measurable part of the cost of small writes, e.g., one row of a table with a text column. A dataset is usually written with the same base data type, so the type of the last write is reused while the base data type stays the same.

Parameters
typeThe base data type of the data in memory.
Returns
The HDF5 type, valid until the next call with a different base data type.
